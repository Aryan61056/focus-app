# beta/

Working folder for beta releases and feedback. See `docs/BETA.md`.

- `BUILD`: the last beta number `tools/beta/release.sh` made. Committed.
- `notes/next.md`: release notes for the next beta. Committed.
- `releases/`: one folder per beta (image, checksum, manifest, invite). Gitignored.
- `inbox/`: reports testers sent, triage state and the summary pages. Gitignored: reports hold what testers typed.
- `testers.csv`: who is testing. Gitignored: names and contacts.
